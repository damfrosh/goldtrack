    STAGE 4 · HISTORICAL SIMULATION

    Historical Backtesting

    Select a saved rule set and a validated OHLC CSV file to run an offline simulation.

    NO LIVE SIGNALS
    i

    Results are historical simulations, not predictions or guaranteed returns. This tool does not fetch market data, execute trades, or save simulated trades to your journal. Short selling is modeled as a simple symmetric position; borrow costs, funding, margin calls, partial fills, and swap are not included.

    No candle dataset loaded. Data is kept in memory and cleared when the page is refreshed.

    Execution assumptions

    • CSV candles must be chronological OHLC with valid timestamps and prices.
    • Rules are checked only at each candle close; entry is at the next candle open.
    • Spread is split around entry/exit; slippage is adverse at each fill.
    • If stop and target are both touched in one candle, stop-loss is assumed first.
    • One open position maximum; no pyramiding. Any position still open at the final candle is closed there with costs.
    • Position units are abstract. Enter a verified currency value per 1.0 price move per unit; no XAUUSD lot/tick value is assumed.
